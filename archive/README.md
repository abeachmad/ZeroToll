# ZeroToll Archive

This directory contains repo content that is intentionally kept outside the active runtime path.

## Sections

- `legacy-services/`: older service implementations and deprecated package-level runtimes
- `experiments/`: prototypes, alternative frontends, and exploratory branches
- `vendor/`: large third-party or reference codebases kept for context
- `root-scripts/`: historical top-level helper scripts that are no longer part of the preferred flow
- `misc/`: leftover root-level artifacts preserved for context

The active local stack does not read from this directory by default.

For the current runtime path, use:

- `README.md`
- `SERVICE_MANAGEMENT.md`
- `start-zerotoll.sh`
