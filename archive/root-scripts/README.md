# Archived Root Scripts

This folder contains one-off or historical helper scripts that used to live at the repo root.

They are kept for reference, but they are not part of the current local runtime or the preferred active toolchain.

Typical contents:

- old cleanup helpers
- one-time fix scripts
- outdated quick deploy helpers
- temporary live-test utilities
- deprecated startup shortcuts
- older manual test scripts that are no longer preferred active entry points

For active utilities, prefer `scripts/`.
