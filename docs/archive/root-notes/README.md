They were moved here to keep the top-level repo focused on active entry points and operational docs.

- deployment checklists and summaries
- testing instructions and verification logs
- EIP-7702 troubleshooting notes

- short-lived implementation summaries

These files are preserved for context, but they are not the primary source of truth for the current local runtime.

For active usage, prefer:

- `README.md`
- `SERVICE_MANAGEMENT.md`
- `docs/README.md`
